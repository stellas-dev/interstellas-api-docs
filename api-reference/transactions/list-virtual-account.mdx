---
title: "List virtual account transactions"
description: "List and search payments received into your business's virtual accounts."
---

## Endpoint

```
GET /clients/business/virtual-accounts/transactions
```

## Headers

<ParamField header="x-api-key" type="string" required>
  Your public API key.
</ParamField>

<ParamField header="x-api-secret" type="string" required>
  Your API secret. Use a `stl_test_...` value in sandbox, `stl_live_...` in production.
</ParamField>

<ParamField header="businessId" type="string" required>
  Your business ID.
</ParamField>

## Query parameters

<ParamField query="page" type="integer">
  Page number. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="integer">
  Records per page. Defaults to `10`.
</ParamField>

<ParamField query="keyword" type="string">
  Case-insensitive partial match across transaction ID, status, transaction type and details, amount expected, amount received, narration, retrieval reference, source and destination account numbers and names, and virtual account reference.
</ParamField>

<ParamField query="status" type="string">
  Comma-separated statuses, for example `completed,pending`. Pass `showall` for all.
</ParamField>

<ParamField query="transactionType" type="string">
  Comma-separated types, for example `credit`. Pass `showall` for all.
</ParamField>

<ParamField query="transactionTypeDetails" type="string">
  Comma-separated sub-types. Pass `showall` for all.
</ParamField>

<ParamField query="amount" type="string">
  Exact amount received, in kobo.
</ParamField>

<ParamField query="virtualAccountRef" type="string">
  Only transactions for this virtual account reference.
</ParamField>

<ParamField query="accountType" type="string">
  `virtual` or `nuban`.
</ParamField>

<ParamField query="dateFrom" type="string">
  ISO 8601 date. Only include transactions on or after this date. Defaults to `2020-01-01`.
</ParamField>

<ParamField query="dateTo" type="string">
  ISO 8601 date. Only include transactions up to and including this day. Defaults to now.
</ParamField>

See [Pagination](/essentials/pagination). This endpoint uses Shape B. Unlike [List transactions](/api-reference/transactions/list), it has no `sortBy`, `amountRange`, `transactionId` or `customerId` filters and no `summary`; results are newest first.
